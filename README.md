🛒 Challenge Alura Store – Análisis de Datos con Python

📌 Descripción del proyecto
Este proyecto forma parte del curso “Practicando Python para Data Science: Challenge Alura Store” dentro de la formación de Data Science de Alura.
El objetivo del challenge es analizar datos de ventas de una tienda, aplicando técnicas de ciencia de datos para generar información que ayude a la toma de decisiones. Durante el proyecto se trabajan habilidades de limpieza, manipulación y visualización de datos utilizando Python.

🎯 Objetivos
Analizar el desempeño de diferentes tiendas.
Identificar productos más y menos vendidos.
Analizar ingresos y comportamiento de ventas.
Generar visualizaciones para facilitar la interpretación de los datos.
Aplicar conceptos de análisis de datos con Python.

🧰 Tecnologías utilizadas
🐍 Python
📊 Pandas
🔢 NumPy
📉 Matplotlib / Seaborn
📓 Jupyter Notebook o Google Colab

📚 Aprendizajes obtenidos
Manipulación de datos con Pandas
Limpieza y transformación de datasets
Exploración de datos (EDA)
Creación de visualizaciones
Interpretación de resultados para toma de decisiones

📌 Conclusión
El Challenge Alura Store permitió aplicar conocimientos fundamentales de análisis de datos con Python, explorando datasets reales y generando información útil para mejorar estrategias comerciales.
